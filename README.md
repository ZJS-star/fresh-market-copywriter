# 生鲜视频群文案工作台

一个面向社区生鲜店的本地视频文案工具：从到货视频抽取关键帧，调用 OpenAI 兼容的视觉模型分析商品，再生成适合微信群发送的促销文案。

## 开源与隐私

- 真实视频、API 密钥、认证文件、调用日志和测试输出不会进入 Git 仓库。
- 请复制 `.env.example` 为 `.env`，再填写自己的 API Key。
- 如果 API Key 曾经出现在公开位置，请立即撤销并重新生成。

给社区生鲜超市每天拍摄的到货视频做画面分析、语音转写，并生成适合微信群直接发送的文案。默认以视频画面为主，语音、清晰标签和补充信息用于修正价格、口感、规格、配送规则。

## 启动

```powershell
npm install
npm run dev
```

打开：

```text
http://localhost:5173
```

## 配置 OpenAI

复制 `.env.example` 为 `.env`，填入你的 API Key：

```text
OPENAI_API_KEY=sk-your-key-here
OPENAI_BASE_URL=https://api.openai.com/v1
OPENAI_TEXT_MODEL=gpt-5.4-mini
OPENAI_TRANSCRIBE_MODEL=gpt-4o-mini-transcribe
OPENAI_VISION_DETAIL=low
OPENAI_COST_MULTIPLIER=1
USD_TO_CNY_RATE=7.25
PORT=5173
```

如果用 OpenAI 兼容代理，把 `OPENAI_BASE_URL` 改成代理地址即可。代理如果按官方价格加倍率收费，可以改 `OPENAI_COST_MULTIPLIER`；人民币估算汇率可以改 `USD_TO_CNY_RATE`。

如果暂时没有 API Key，也可以在页面里手动填写今日到货内容，然后点“本地草稿”看流程。

## 每天使用流程

1. 上传今天拍的新到水果视频。
2. 点“分析画面”，检查视频里识别出的水果、成色、包装和卖点。
3. 点“转写语音”，检查价格、规格、口感有没有转错。
4. 在“今日补充”里写清楚价格、规格、主推、配送时间。
5. 点“生成微信群文案”。
6. 复制日常版、精品版或短促版发到对应微信群。

页面会显示“本条视频估算成本”，并把每次调用记录到 `data/usage-log.jsonl`。记录包含模型、token、转写时长、估算美元成本和接口耗时。

省钱测试方式：先点“分析画面”，确认摘要后再点“生成微信群文案”。这样生成时会复用摘要，不重复发送图片；如果跳过分析，生成按钮会直接带关键帧请求模型。

## 建议输入格式

```text
阳光玫瑰 19.8/斤，脆甜，今天主推
云南蓝莓 2盒29.9，适合孩子吃
榴莲 20/斤，香糯甜，今天主推
下午5点前下单，周边小区可配送
```

## 注意

- 上传文件建议控制在 25MB 以内。
- 画面分析默认抽取 6 张关键帧；如果视频很长，建议只截取今天介绍重点商品的片段。
- 群发文案不解释下单和付款流程，重点写主推水果、口感品质和价格吸引力。
- 不要写医疗功效、全网最低、绝对甜等容易引起纠纷的表达。
